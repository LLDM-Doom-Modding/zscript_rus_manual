# Стейты актора

Стейты позволяют анимировать, задавать задержки и исполнять функции в определённые моменты времени. Язык конфигурации стейтов очень похож на Decorate.

Важно отметить, что само понятие "стейт" часто трактуется неверно — под ним при свободном общении может подразумеваться что угодно из списка ниже. Корректнее считать так:

* State ("состояние" актора, общепринято называть его "стейт") — это один кадр анимации актора вместе с назначенным действием.
* State Sequence (последовательность стейтов) — несколько стейтов, идущих друг за другом.
* State Label (название стейта, метка стейта) — только название, удобное обозначение начала последовательности стейтов. В руководстве практически всегда обозначается с двоеточием в конце (например, `See:` или `AltFire:`),

То есть тут один стейт (подробнее см. в [разделе "Правила записи стейтов" статьи 2.2](../../2-Первый_мод/2.2-Простой_декоративный_актор.md#правила-записи-стейтов)):
```CPP
TROO A 10 Bright;
```
Вот последовательность из пяти стейтов:
```CPP
TROO A 10 Bright;
TROO BC 7;
TNT1 A 0 A_Explode();
TROO D 15;
```
А здесь уже последовательность стейтов, озаглавленных названием "`Spawn:`":
```CPP
Spawn:
	TROO A 10 Bright;
	TROO BC 7;
	TNT1 A 0 A_Explode();
	TROO D 15;
    Loop;
```
Сам блок стейтов задаётся ключевым словом `States {}`, например:
```CPP
States {
Spawn:
	TROO A 10 Bright;
	TROO BC 7;
	TNT1 A 0 A_Explode();
	TROO D 15;
    Loop;
}
```


## Как работают стейты

	Раздел находится в разработке. Здесь также будут иллюстрации...

Говоря крайне формальным языком,

* State — это минимально адресуемая запись в массиве конечного автомата состояний актора.
* State Sequence — это однонаправленно соединённая при компиляции череда состояний вплоть до прерывания или зацикливания.
* State Label — это мнемонический указатель типа `Name` на конкретный стейт.

Стейт-машина (подстистема актора, отвечающая за смену стейтов) начинает последовательное исполнение от стейта, на который указывает метка стейта `Spawn:`. Если в стейте есть какое-то действие — исполняет его, затем приостанавливается на указанную в стейте задержку. Как только время задержки вышло, переходит на следующий стейт.

В случае прерывания текущий стейт вне зависимости от оставшейся задержки переходит туда, куда указывает прерывание. При необходимости перехода монстра в анимацию боли, например, текущая последовательность стейтов прерывается в пользу последовательности стейтов, начинающейся с метки стейта `Pain:`.

Подробнее вопрос можно изучить в статье "[Как на самом деле работает стейт-машина](../../8-Внутреннее_устройство_движка/kak-na-samom-dele-rabotaet-steit-mashina.md)".
