# Введение

Добро пожаловать в руководство по изучению скриптового языка для (G)ZDoom-совместимых портов — ZScript!

!!! warning
    Внимание! Проект находится на ранних стадиях разработки. Пока что в тексте статей будут встречаться комментарии разработки, неточности, неясные формулировки и опечатки.


## Быстрый старт {#быстрый-старт}

Основная статья быстрого старта [находится здесь](1-Введение/index.md).

Копия важных пунктов:

- [Оглавление руководства](SUMMARY.md).
- Если интересует конкретная тема, то с помощью <a href="javascript:javascript:document.getElementById('__search').click()" style="text-decoration: underline;">строки поиска</a> её можно сразу найти. На клавиатуре поиск также вызывается по клавише `/` или латинской `s`.
- В [статье "Полезные ссылки"](1-Введение/1.4-Полезные_ссылки.md) есть в том числе и каналы/форумы, куда можно обратиться за помощью.
- В [разделе "Примеры"](Примеры/index.md) лежат готовые примеры кода.
- Ошибка? Сообщить можно в любом месте, где она не потеряется!
