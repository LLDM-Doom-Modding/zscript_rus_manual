# Русскоязычное руководство по ZScript

[Сайт руководства по ZScript](https://zscript-rus-manual.readthedocs.io/), там же есть [быстрый старт](https://zscript-rus-manual.readthedocs.io/latest/#быстрый-старт) и [страница содержания](https://zscript-rus-manual.readthedocs.io/latest/SUMMARY/).

Основной репозиторий проекта: https://github.com/LLDM-Doom-Modding/zscript_rus_manual/.

Тема на Russian Doom Community (iddqd.ru): "[Разработка руководства по ZScript — анонс!](https://i.iddqd.ru/viewtopic.php?t=2845)".


_Внимание! Проект находится на ранних стадиях разработки. Пока что в тексте статей будут встречаться комментарии, опечатки, блоки "TODO:" и неясные формулировки._


## Как сообщить об ошибке или предложить вариант улучшения

Можно написать [в issues на GitHub](https://github.com/LLDM-Doom-Modding/zscript_rus_manual/issues), или в личные сообщения, или в каналы вроде `#modding` на русскоязычных Discord-серверах по Doom Community, или в [тему разработки на RDC](https://i.iddqd.ru/viewtopic.php?t=2845). Главное — чтобы информация не потерялась и чтобы кто-нибудь, кто может всё исправить, увидел сообщение.


## Как присоединиться

_Основная статья — ["1.3. О проекте руководства", раздел "Как присоединиться"](https://zscript-rus-manual.readthedocs.io/latest/1-%D0%92%D0%B2%D0%B5%D0%B4%D0%B5%D0%BD%D0%B8%D0%B5/1.3-%D0%9E_%D0%BF%D1%80%D0%BE%D0%B5%D0%BA%D1%82%D0%B5_%D1%80%D1%83%D0%BA%D0%BE%D0%B2%D0%BE%D0%B4%D1%81%D1%82%D0%B2%D0%B0/#%D0%BA%D0%B0%D0%BA-%D0%BF%D1%80%D0%B8%D1%81%D0%BE%D0%B5%D0%B4%D0%B8%D0%BD%D0%B8%D1%82%D1%8C%D1%81%D1%8F)._

Проект создаётся [под открытой лицензией](LICENSE). Так что, из основных вариантов:

- Сделать [Pull Request в основной репозиторий](https://github.com/LLDM-Doom-Modding/zscript_rus_manual/pulls), основная ветка — `master-readthedocs`.
- Приложить новую/расширенную/исправленную статью на любой из ресурсов, где изменение смогут увидеть разработчики проекта (например, [в тему на iddqd.ru](https://i.iddqd.ru/viewtopic.php?t=2845) или [создать Issue на GitHub](https://github.com/LLDM-Doom-Modding/zscript_rus_manual/issues)). В этом случае авторство правки сможет быть указано только в разделе благодарностей и в описании коммита.
- Написать администрации с просьбой выдать write-доступ в основной репозиторий.

 При использовании других статей нужно указывать ссылку на первоисточник и соблюдать его лицензию. Использование LLM допустимо, однако ответственность за результат полностью лежит на живом авторе коммита.
